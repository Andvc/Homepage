🐱 My Cat Homepage

当前状态: Idle

🎮 互动指南

  • 场景物品交互：点击场景中的物品，猫咪会做出相应动作
    • 🍽️ 食碗/水碗 → 吃饭
    • 🛏️ 猫窝 → 睡觉
    • 🎢 猫爬架 → 兴奋玩耍
    • ⚽ 玩具球 → 玩球跳舞
    • 📚 架子 → 躺下
    • 🌿 植物 → 好奇惊讶
  • 拖拽猫咪：按住鼠标拖动猫咪到任意位置，猫咪会兴奋
  • 点击猫咪：在不同状态下点击会有不同反应
  • 自动行为：猫咪会根据状态自动转换动作

🔄 自动状态流程

待机 → (5秒) → 困倦 → (1秒) → 睡觉
睡觉 → (点击/拖动) → 惊讶 → (2秒) → 待机
吃饭/玩耍 → (完成) → 待机

💡 提示：点击"显示/隐藏热区"按钮可以看到所有可交互区域
